# 类型系统迁移的已确认合同

本文件保存用户确定的语义与边界。最新实现状态、固定剩余清单和验证结果只维护在 [续接记录](./session-continuation-2026-10-04.md)；语言规则见 [规范](./specification.md)，实现接点见 [实施入口](./next-stage-plan.md)。最新用户指令优先。

1. `object` 是普通值的静态超类型；`any` 可以利用实际类型知识。DataObject 保留为模板基类；原始 nbt 不是所有可编码类型的父类型。
2. 日常算术使用 int/float，允许 int→float 提升。byte/short/long/double 与 NBT 数组保留精确格式；bool 的 ByteTag 编码不使其成为 byte。
3. object 只开放公共签名。any 的实际类型唯一已知时可以绑定操作；未知或有多个候选时，具体操作须显式 as。不新增类型标签或运行时自动分派。
4. TypeId 独立于显示名；别名透明，泛型身份包含全部实参，联合类型规范化。关系与重载查询纯粹，按精确、具体名义父类、数值提升、object、any 选择；同级歧义诊断。
5. Symbol 保存声明身份和约束，ValueRef/Place/TypedView/FlowFacts/StorageLayout 各司其职。类型知识与值知识独立；未初始化、空值、错误和不可达分开。常量载荷不能引用可变 Var、Tag 或作用域。
6. 语言移除 `T!`。`type` 仅用于泛型参数，普通变量、字段、参数/返回以及擦除值或容器不能存放类型值。`const` 只限制重赋，不要求编译期已知，不冻结容器内容；dynamic 要求运行时表示。
7. `as` 解释同一个 Place，不调用构造器、不补字段、不复制、不转换数值。any 来源不检查运行时类型；普通来源无法证明兼容时警告。实际目标布局不可访问时诊断，并建议转换函数。
8. 数值转换使用 toInt/toFloat/toByte/toShort/toLong/toDouble，toNBT 生成来源编码。未知 any 没有兜底；不以常量专用实现假装运行时支持，未证明后端等价时保留实际操作。
9. 模板结构查询处理必需/可选与额外字段、只读递归、可写不变、访问控制、循环和抽象能力。静态成员及构造器不参与形状比较；使用目标方法。
10. 多个视图共享位置；普通复制建立独立位置。写入撤销重叠事实和版本缓存，无法定位的效果保守失效；不将模板普通赋值改为引用赋值。
11. 使用基本块与显式读写的轻量 IR，不要求完整 SSA。分支只汇合可达路径，循环求保守不动点，break/continue/return 与所有出口参与分析。
12. 用户函数有实际效果摘要；未标注原生调用与原始命令按未知效果处理。观察前物化延迟写入，随后撤销可能变化的事实和缓存。
13. 物化与失效分离；形参、返回、活跃临时值、递归帧和实体路径使用同一存储接口。后端按目标能力选择，不猜测未知版本，不重排浮点求值顺序。
14. any/object 共用擦除载荷机制并保留来源编码。编译器专用值不能因 object 获得运行时布局；其普通调用按完整实际载荷绑定，不作为普通常量特化缓存。
15. readonly 泛型实参要求完整不可变载荷；特化键包含声明、全部实参、目标能力与生成选项。普通参数的常量组合不进入特化键，不为优化执行用户函数。
16. 一个语言成员只有一份签名。可达原生接口使用 NativeCallContext 与值/位置合同；库只持久化声明，不保存调用缓存和实例作用域。删除旧双层值语义与临时适配。
17. 不新增编译期用户函数、lambda/跨 tick/异常、运行时反射、公开 ScoreRef/NBTRef、泛型上界或新推导、通用优化框架，以及自动持久数据迁移。旧浮点与 26.3 布局不自动互换。
