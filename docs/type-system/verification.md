# 类型系统迁移的验证方法

实际状态与最近结果只维护在 [续接记录](./session-continuation-2026-10-04.md)。本文件说明如何核验合同，避免把限定用例或旧报告误记为完整迁移。

## 构建与库

使用项目声明的 Java/Gradle 版本。对每个完整修改批次运行编译与受影响回归；已经通过且未受新修改影响的用例不重复。库元数据变更集中升级格式并运行 `regenerateStdlib`，核对任务退出、语言错误/警告、实际 MCFL 头与资源一致性，再验证旧/未知格式的重编译诊断。

最终统一执行构建和覆盖迁移的相关回归。核对 Git 差异、空白检查及提交范围；每个通过验证的完整批次本地提交，不推送，不纳入用户另行创建的设计文档。

## 语言与声明

检查普通值位置和嵌套容器拒绝 type、泛型 type 参数合法、T! 语法拒绝、const 仅限制重赋。泛型覆盖方差、重复名字、配对伴随对象、readonly 完整载荷、权限和源码/fresh 身份一致性。

RHS 绑定与签名查询不得执行用户函数或构造函数。检查真实初始化次数、独立实例、多级继承的声明 owner、重载、抽象能力、词法默认值、属性字段位置和导入 object 初始化。普通实参不能改变公共参数契约或加入特化键。

源码与 fresh 库都必须检查容器实参（如 `dict<Node>`）中嵌套声明的实例字段：访问/复制不得使用无字段占位，字段读取、复制和返回的初始化证据须与源码一致。递归模板覆盖实际深层读取、独立复制、返回与修改隔离，并保留循环保护及显式未初始化字段反例。普通传入形参本身具有入参初始化状态，但其源键/后代不得因局部访问推导而新增持久 INITIALIZED、常量或长度事实，形参快照与普通值特化缓存必须为空。不删除断言或以成功旧日志代替本轮执行。

## 值、控制流与效果

使用实际导出的命令检查已知与未知值、null、UNINITIALIZED、MAYBE_INITIALIZED、ERROR 和 UNREACHABLE、可达分支汇合、循环不动点及全部出口。检查普通 copy 独立、as 同 Place、来源与访问声明的双重权限、兄弟字段事实保留、动态下标与别名失效、原始命令观察和调用效果。

const 验收同时包含合法的首次赋值、可变内容、static 内容写回，以及分支/循环/别名的非法重赋。非法写入须保留原事实；循环体中的局部声明每轮重新开始生命周期。readonly 容器与后代修改仍须拒绝。

dynamic 验收检查实际运行时表示、保留的已证明事实和真实运算命令；编译器专用载荷不能凭 dynamic 或 object 获得存储能力。效果验收区分纯调用、字面 say 的只读观察和未知命令屏障，并检查观察前物化及屏障后的重叠事实失效。

连续、嵌套、递归调用保留较早实参、返回和活跃临时值；所有实际出口帧平衡。覆盖标量、擦除值、集合与数组、模板、编译器专用载荷、未知整数 range 端点、现有迭代器和实体位置。捕获位置在调用帧变化后仍对应原操作数；普通公共形参的重载契约不因实际编译器专用载荷而改变。未知返回不能伪造常量或初始化证据。

## 原生接口与数值

源码和重新读取的库均检查 NativeCallContext 的真实 receiver、参数、结果发布、权限与效果。Selector 全部过滤、命令参数消费者、资源工厂及 BossBar 属性使用普通已知/未知值；核查单次发射、捕获顺序、独立副本、动态字符和能力错误，错误不得发布结果。Area 未知坐标与 `^` 局部坐标作为明确诊断反例，Slot 运行时编码按目标宏能力判定；不能把这类反例通过写成运行时 Area 坐标支持。

原生 ABI 注册反例须检查注解函数/操作符注入及显式 native func 绑定拒绝非单 NativeCallContext 的宿主签名，且失败不插入对应成员或操作符。属性检查单上下文原生选择及失败调用不发布有效结果；未匹配引用可进入语言表达式属性绑定，不能将此路径描述为无成员注册。实际验证状态见续接记录，接口清理前通过的回归不能替代其后验证。

数值验证组合目标版本、Native/IR、折叠开关和源码/fresh。使用独立命令执行器对照实际结果，旧浮点执行真实库辅助函数；覆盖精度、符号零、异常输入、连续捕获和实体只读来源。嵌套 NBT、DTO、参数、返回与独立副本保留精确 Tag 类型及浮点符号零。保持不支持转换的诊断，26.3 不调用旧浮点辅助函数。

## 证据边界

以实际进程退出和本轮逐项结果为准。工作进程致命退出使该轮验证失败；未执行的用例不能计为通过。旧 XML、缓存报告或日志中的 BUILD 文本不能代替当前实际退出及新报告。Gradle 成功也须核对语言诊断和结果断言。

正向用例检查生成命令及数据、返回、副作用次数或帧；反向用例按合同检查诊断及未发布结果，涉及失败原子性的路径还检查无新增命令、原事实与兄弟字段保持。现有部分反例仅断言错误计数或失败结果，不能描述成全部逐字校验诊断文本。执行器严格拒绝未知指令，不能跳过真实辅助函数或用宿主折叠替代后端行为。

验收工具可保存实际退出的最外层帧，供程序结束后的结果断言读取；只观察真实移除帧中的数据，不改变执行期间的读取、帧深度或程序存储。结果按实际生产者布局读取，缺失数据仍报错，不以编译期事实补值。

当前没有配置 Minecraft 服务端；导出命令与独立执行器验证不能描述为游戏世界、聊天渲染或实际服务端验证。
