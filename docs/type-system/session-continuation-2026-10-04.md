# 类型系统续接记录

更新：2026-10-08。目标仍在进行中。规范以 specification.md、session-handoff-2026-10-04.md 的既定要求及 design-decisions-2026-10-07.md 的已确认决策为准；最新用户指令优先。

## 已完成

- 语言层 `T!` 已移除；`type` 仅允许泛型参数，普通变量、字段、参数/返回和容器不得存放类型值；`const` 只限制重赋。readonly 泛型绑定仍要求完整、不可变的编译期实参。
- 类型身份、透明别名、联合归一、object/any、名义重载与精确 NBT 数值规则已有实现及回归；不因相同存储格式建立类型关系。
- 标量、擦除值、可编码集合/数组、模板字段、视图共享与普通复制、调用帧和两种浮点后端已有受测路径；下面的统一迁移和旧体系删除尚未完成。
- 已迁移多数原生接口；退役不可达宿主入口。最新完整批次将 ItemPredicate 六个实例构建方法和六个静态工厂迁入显式上下文，正确保存各字段、返回值和独立副本；模板根部空列表初始化使用声明元素类型。库格式为 MCFL74。

## 固定剩余清单与验收

以下为固定范围，不能删除、推迟或降低验收以宣称完成。现有受测行为是基线；只为受影响路径补验证。

1. **泛型声明与伴随合同**
   - 声明处 `out T as type` / `in T as type`，默认不变；检查字段、方法及嵌套类型的位置，值实参不参与方差；禁止语言星投影。
   - 同一命名空间 data/object 各自名字唯一，清除按泛型数量/种类选择同名声明的路径；保留 data/object 配对、不同实参身份及函数/构造重载。
   - 非泛型伴随对象共享；对应泛型对象按同位置实参配对，绑定与私有权限分别判定，状态不混淆。只处理同数量/参数种类的明确对应，不增加待定的映射、推导或上界语法。
   - 验收：正反方差、嵌套违规、可变容器不变、无数值提升方差；声明顺序/跨文件重复诊断；共享/隔离状态、真实成员类型和权限；源码与 fresh 库恢复一致。

2. **Selector 原生接口族**
   - 全部 27 个过滤接口使用 NativeCallContext；保留普通已知/未知 int、string、range、NBT 和 DTO 参数及原 receiver 变更语义。
   - 完整不可变快照、独立复制、重复标志和动态来源捕获保持一致；参数后续修改不改变已捕获过滤条件。
   - 验收：连续调用、正反过滤、复制与独立修改、重复诊断、真实动态宏来源和单次发射、无普通参数常量特化；源码/fresh 签名和行为一致，错误不发布结果。

3. **命令格式与资源工厂接口族**
   - Area/Slot 的实际命令消费者通过值/位置接口读字段；移除 DataObject 公共 JavaVar formatter 和对应宿主调用桥。
   - Predicate.of 支持普通动态 id，发布真实 DTO 值与位置；保留 pass/fail 消费者合同。
   - 验收：已知与未知坐标/槽位/id、正确编码及宏来源、字段修改/复制、不可编码输入诊断；源码/fresh 实际导出命令一致，不以宿主打印结果替代断言。

4. **属性与宿主调用接口族**
   - BossBar max/value/visible 三组 get/set、NativeAccessor/NativeMutator 返回及变更合同接入显式上下文。
   - 清理无语言绑定的 World.time/Worldborder getter 旧注解，不增加新语言 API；统一剩余可达 native 构造、迭代与反射消费者，删除 NativeFunction 的 ValueWrapper 后备分派。
   - 验收：所有语言可达 MNI 方法使用单上下文，属性 getter 真实返回、setter effects 正确，源码/fresh 权限/签名一致；剩余宿主载荷只限内部描述能力，不能成为普通值或语言反射入口。

5. **声明推断、模板与用户调用合同**
   - 已支持的普通初始化 RHS 通过共享绑定/类型分析确定声明类型，删除 extraFunction 执行探测；真实初始化只执行一次。
   - 普通函数/构造实参不按调用处常量改变类型契约；泛型按完整实参特化。成员、构造、抽象能力、词法环境和导入 object 初始化采用真实 owner/位置。
   - 验收：自由函数、成员/泛型 RHS、多级字段、不同构造重载、源码/fresh 初始化均无试算命令或调用图副作用；重载推断冲突诊断；每个实际对象只初始化一次，独立实例不覆盖。

6. **控制流、效果、存储与调用统一**
   - 全部现有语言表达式、签名、调用及控制流统一读取 ValueRef/CompilerValue/Place；类型与值事实独立，uninitialized/null/error/unreachable 分开。
   - 完成未知整数 range 端点及现有迭代器的绑定和运行时路径，不将已支持语法留在 Concrete 判断分支；分支只汇合可达路径，循环求不动点，break/continue/return 正确。
   - 效果摘要覆盖成员、集合、浮点、全局、实体及递归擦除返回；观察前物化，未知调用/原始命令后撤销重叠事实与版本缓存。
   - 活跃值、实参/返回、临时值、递归帧和实体位置采用统一存储接口；删除 hasStoredInStack、trackLost、Concrete/MCFPPValue 双层语义和双成员表及临时迁移适配。
   - 验收：嵌套/连续/递归调用不覆盖活跃值，别名及动态下标保守失效，兄弟字段事实保留；any/object 已知/未知类型的成员及重载边界正确，未知返回不伪造常量；折叠开关不改变行为，所有可达出口帧平衡。

7. **集合、视图、数值和后端收尾**
   - 当前集合、编译器专用完整载荷、模板、实体和动态索引采用统一事实/编码/读写；语言 as 始终同 Place，不构造、补字段、复制或数值转换。
   - 完成约定的 toInt/toFloat/toByte/toShort/toLong/toDouble/toNBT 具体源合同和标准库/示例迁移；不把不可实现目标伪装成常量专用转换。按实际后端明确范围、舍入和能力诊断。
   - 验收：普通 copy 与 as 共享区别、精确 NBT 数组格式、空/异质容器能力、静态载荷完整性、动态索引；新旧 float 的常量/运行时规则一致，26.3 无旧浮点调用，旧后端不作未证明的宿主折叠；不支持的布局/运算明确诊断并给可行转换建议。

8. **最终清理与整体回归**
   - 所有固定项兑现后统一更新规范、迁移说明和示例；移除死适配与旧兼容路径，代码保持简洁。
   - 库 ABI 修改集中升级、重建标准库并验证旧缓存要求重编译；最终运行覆盖整个迁移的构建和相关回归，每个完整验证批次本地提交，不推送。
   - 验收：以上全部勾清，构建/回归通过，实际提交与工作区核对；不得把限定用例通过描述为完整语言或 Minecraft 服务端验证。

不添加待定功能：lambda/跨 tick/异常或新效果语法、公开 ScoreRef/NBTRef、泛型上界/推导新规则、通用交叉类型、运行时反射/标签/自动分派、通用优化框架，以及已有持久数据的自动布局迁移。现有后端有明确诊断的能力限制须保留，不能据此删掉统一迁移任务。
