# MCFPP 类型规范（重构目标与实现边界）

此文档描述本次迁移的稳定语义合同。实际接入状态、剩余边界与验证结果只维护在 [续接记录](./session-continuation-2026-10-04.md)；后端能力限制以 [转换合同](./conversions.md) 的明确诊断为准。

## 类型身份

显示名不参与类型身份。内建类型有固定 TypeId；模板、接口和枚举采用类别、命名空间与声明名。
泛型实例的身份包含构造器及全部参数。联合类型去重、展开嵌套并规范排序。
语言不提供 `T!` 类型后缀。类型值只能作为泛型参数声明，例如 `data T<t as type>`；普通值声明 `x as type=int` 非法。`const` 只限制重赋，不要求初始化值在编译期已知；readonly 泛型绑定仍要求完整编译期快照。
别名解析后透明地使用被指向类型的身份。
未解析类型、泛型占位符、void 和内部静态成员视图不属于普通值类型。

## object、any 与 DataObject

object 是统一静态超类型。int、float、bool、string、NBT 映射类型、集合、模板、any 及非 type 编译器载荷均可向上解释为 object；TypeValue 不能借 object/any 绕过普通值位置限制。
object 的成员由其公共签名决定，知道来源类型不会增加其成员。
any 是擦除类型：实际类型唯一已知时使用该类型绑定操作；未知或有多个候选时，具体操作须显式 as。不引入运行时类型标签或自动分派。
DataObject 仍是数据模板基类，位于 object 下；nbt 表示原始 NBT，不是所有可编码类型的父类。
内部静态成员访问对象名为 StaticMemberView。

## 隐式转换与重载

查询从实参类型指向形参类型；查询本身不能生成命令或修改变量。
int 可以提升到 float，反方向不允许隐式转换。
NBT byte / short / long / double 不继承普通 int / float 算术语义；bool 的 ByteTag 编码不改变类型身份。
泛型声明支持 `out T as type` / `in T as type`，未标注时不变；方差依据名义子类型关系并检查嵌套输入/输出位置，不沿用数值提升，也不提供语言星投影。可变容器参数保持不变；ImmutableList 使用只读列表接口，但该内建类型仍保持泛型不变，不因只读接口自动增加协变转换。
重载按精确匹配、名义父类型、int 到 float 提升、object、any 排序；同级选择最具体候选，否则报歧义。
缺省实参只在对应参数声明默认值时省略；单一候选也必须验证实参。

## 值与数据位置

Symbol 保存声明身份、声明类型与约束；Place 保存底层位置和字段或索引路径。Location 同时保留求值时捕获的下标、键、调用帧和实体来源。
ValueRef 与 TypedView 不拥有新的数据身份。as 保留来源位置与来源声明约束；普通复制建立独立位置，声明别名不重新初始化来源。
公共声明类型决定成员、重载与访问权限；实际载荷和生产者布局决定捕获、复制及编码。object 不因已知来源而获得额外成员，编译器专用载荷不因擦除为 object/any 而获得运行时布局。普通调用按实际载荷绑定，不按普通实参的常量组合特化，也不改变公共参数和返回契约。
类型信息 Exact / Candidates / Unknown 与值信息 Constant / Partial / Program / Unknown 独立。CompilerValue 是不可变的完整载荷；Selector 的有限 Program 可以包含已捕获运行时操作数，因此不能作为 readonly 泛型的完整编译期实参。
值状态 UNINITIALIZED、MAYBE_INITIALIZED、INITIALIZED 和 ERROR 分别表示未赋值、部分路径已赋值、已赋值和错误；不可达由控制流可达性表示。null 是明确的值，不能代替未赋值。常量载荷不可引用可变 Var 或 NBT Tag。
dynamic 要求可用的运行时表示；物化保留已证明的类型、值和形状事实。运行期运算仍须发射真实命令，不能用保留的事实代替执行。写入失效重叠位置和存储缓存；动态索引保守地覆盖潜在元素。
控制流汇合只保留所有可达前驱共有的信息；循环通过保守不动点求解。const 首次赋值要求所有可达前驱均证明该位置未赋值，Unknown 或 MAYBE_INITIALIZED 不构成证明；每次进入循环局部声明开始新的声明生命周期。
const 容器的内容仍可修改，readonly 约束则覆盖内容与后代。写入同时检查访问声明和来源声明；非法写入不提交值事实或调用写回效果。
未知字典的具体键访问可消费已绑定元素类型的可读布局，但类型证据不证明键存在。访问局部的字段证据通过同一事实接口读取；实际复制或返回可将证据传给独立目标，不能据此给源键新增持久 INITIALIZED、常量或长度事实。递归布局按实际访问路径处理，显式 UNINITIALIZED、MAYBE_INITIALIZED 和 ERROR 不得被声明布局覆盖。

## as 与转换函数

as 建立同一 Place 上的解释视图，不调用构造器、不补字段、不复制对象、不转换数值。
不兼容的普通来源给警告；any 来源不进行运行时类型检查。
目标没有可用的存储访问方式时给代码生成错误，并建议转换函数。
数值转换使用 toInt / toFloat / toByte / toShort / toLong / toDouble；toNBT 生成来源约定的编码。
常量转换与运行时后端遵守相同规则；无法证明等价时不得用宿主强转折叠。
结构形状只决定重解释是否需要警告，不产生隐式模板子类型关系。

## 后端与副作用

存储包含记分板、NBT、旧浮点分量、未物化常量和编译器专用载荷。
编译器专用载荷不能通过 object 获得运行时存储能力。
语言可达原生接口只接收一个 NativeCallContext，通过同一值、位置和效果接口发布返回或写回；宿主包装器不作为语言分派后备。
未知效果的原始命令与未标注原生调用是外部状态屏障；纯调用不失效事实。有限例外为不含插值标记或换行的字面 say 命令，归为 ReadsRuntime，只观察已物化值。观察前物化，随后按实际效果撤销可能变化的事实和重叠缓存。
26.3 数值提供器后端与旧模拟后端具有各自的常量求值规则，禁止改变浮点求值顺序。
