# 类型系统迁移指南

语言规则以 [规范](./specification.md) 为准。本次迁移不兼容旧语言写法，也不自动转换已有持久数据。
类型组合与工厂改动仍按 [实施记录](./composition-implementation.md) 记录集成与验证状态；以下写法说明目标合同，不代表所有检查已经通过。

## 语言写法

声明使用 `var name: Type`，具名参数和字段也用冒号；`const`、`external` 声明不加 `var`，导入变量仍用 `import var`。表达式视图、导入别名、`typealias` 和 data 视图的 `as` 保留。

`type` 只用于泛型参数。例如 `data Box<T>` 合法，`<T>` 等价于 `<T: type>`，readonly 值参数写作 `<N: int>`。普通变量、字段、函数参数或返回值不能存放类型值，嵌套在 any/object 或集合中也不例外。`typealias` 和直接泛型类型表达式保留。

`if`、`else if`、`while`、`do ... while` 条件括号可省略，条件须为 `bool`。换行或块结尾无需分号；同一行语句间和 SNBT 数组内的分号保留。

语言不提供 `T!` 后缀。每个 `const` 声明必须带有完整编译期初值，并深度保护其真实数据位置。运行时初值、缺少初值和含未知部分的聚合均非法；关闭常量折叠也遵守同一规则。readonly 泛型实参同样要求完整、不可变的编译期载荷。

data 固有 const 字段在模板或泛型特化完成时固定，合同使用其字面量类型。显式对象字面量必须提供该字段及匹配的值，目标类型不再自动补入常量。将原先由运行时构造参数赋值的 const 字段改为 `var value: int { get }` 等运行时只读属性，并在工厂返回的对象中提供它。需要修改内容的普通局部值改用 `var`。as 视图保留来源保护，复制到独立 var 后可以修改普通字段，模板固有常量继续受保护。

可选字段的 `== null` / `!= null` 检查后备位置，`= null` 删除后备位置，均绕过 getter/setter。普通读取需要存在证据；删除、相关方法写入和控制流合流会更新或撤销证据。纯计算属性没有隐式后备位置。

模板字段 `var label: string?` 表示允许缺失；对象字面量中省略它，不能用 `{ label: null }` 作为字段值。可选语法仍只用于模板字段。可选 `never` 字段只能缺失。

无上下文的 `{ x: 1 }` 推断对象字段合同；需要同质字典时显式写 `var values: dict<int> = { x: 1 }`。`{ x }` 从当前词法环境读取 x，空对象写作 `{}`。重复键编译报错，包括 `x` 与 `"x"`；不提供对象展开。目标对象合同允许额外字段，缺少必需字段或字段类型不符仍报错。

对象类型写作 `{ x: int }`，组合类型写作 `(A & B)`、`(A | B)`。赋值、参数、返回和约束使用结构子类型。交叉合并同名字段约束；联合成员必须由所有分支提供，写入值必须满足每个分支。`as` 保持显式解释视图语义，结构不兼容本身不会拒绝它；共享位置写入仍检查真实存储合同。

源码匿名 `data { ... }` 迁移为具名 data 或公开子模板。`Outer.Inner` 统一用于类型位置、构造、as、继承和库导入；导入 Outer 同时公开其子模板。外层与内层泛型参数按声明层次依次绑定，例如 `Outer.Inner<2>`；绑定值参与子模板身份。

external 要求运行时表示，不能将编译器专用载荷强制编码为 NBT。物化保留已经证明的事实，后续运行期操作仍生成真实命令。

`as` 产生同一数据位置上的临时解释视图；赋值给变量时复制到目标的独立位置，声明初始化也遵守此规则。需要共享引用目标时使用 Ref 系列类型。显式数值转换使用 `toInt`、`toFloat`、`toByte`、`toShort`、`toLong`、`toDouble`；编码使用 `toNBT`。能力与精度见 [转换合同](./conversions.md)。

泛型声明支持 `out`、`in`，默认不变；内建 list/dict/map/ImmutableList 的类型参数均保持不变，ImmutableList 的只读接口不引入协变。不提供语言星投影。同一命名空间的 data/object 名字分别唯一，明确对应的伴随对象按声明参数配对。

## 声明、初始化与调用

公开的 `ref expression` 取地址语法已移除。使用 `ScoreRef`、`NBTRef<T>` 及显式地址工厂；实体的 `target.score[objective]` 和 `target.dat.field` 直接产生引用值。普通参数、返回、data/list 和普通 lambda 捕获复制引用描述，`r = otherRef` 更换描述，`r.set(value)` 写入目标。普通局部变量不开放取地址，旧 `REF int` 也不自动接受 `ScoreRef`。完整的创建、同步读取、上下文借用及迁移示例见 [引用值](./reference-values.md)。

字段 RHS 的声明类型来自纯绑定与签名查询，绑定不执行用户函数或工厂。字段初值仅用于生成隐式工厂，显式对象字面量和显式工厂返回之后不再执行隐藏初始化。普通实参的已知值不改变公共参数与返回类型；编译器专用载荷在实际调用中绑定，只有 readonly 泛型实参进入特化键。

将 `constructor` 与对预分配 `this` 的赋值迁移为返回完整对象的 `new`：

```mcfpp
data Point {
    var x: int
    var y: int
    new(x: int, y: int) { return { x, y } }
}
func main() { var point = Point(2, 3) }
```

`Point(2, 3)` 与 `Point.new(2, 3)` 使用同一工厂重载。工厂返回类型为所属模板的 `Self`，没有隐式 `this`，所有可达成功路径必须显式 `return`。字段初值足以满足本地完整合同才生成零参数工厂；空模板生成返回 `{}` 的工厂。显式零参数工厂替代隐式版本，其他重载并存。

父初值和父工厂不再自动执行。子工厂必须自己构造完整父字段；需要父工厂结果时显式调用并组合。`this.Parent.new(args...)` 只适用于名义父模板，等价于 `Parent.new(this, args...)`，因此 Parent 的工厂需要显式声明接收该值的第一个普通参数。工厂自身没有隐式 `this`，使用显式参数访问所需数据。

继承只组合数据字段。移除依赖继承函数、覆盖或 `super` 分派的写法；模板函数按带接收者的自由函数处理。兼容的同名普通字段合并，同源菱形路径去重；父合同中普通字段与 const 字段同名始终报错。字段初值和函数不参与对象类型身份。

纯闭合的普通默认表达式可通过声明绑定保存不可变载荷；依赖 receiver 或普通变量的默认表达式保留词法 AST，不执行初始化探测。缺省实参只在实际省略时求值，并使用声明的词法环境、已绑定 readonly 实参、此前普通实参及实际 receiver。属性 getter/setter 使用真实 owner 和字段位置；表达式属性保留词法 token 间隔，内部访问函数不占用用户可声明的名字。

object 初始化采用规范声明身份，并按依赖执行一次。库恢复重建声明环境与实例访问作用域，不保存源项目的调用图、活跃位置或特化缓存。嵌套在容器实参中的声明身份同样解析到真实声明；访问与独立复制/返回从同一 `readAccess` 和当前 StoredData 的类型描述读取布局，不使用公开无字段占位。访问局部的布局证据只能向独立目标传递，不给源字典键发布 INITIALIZED、常量或长度事实，不改变普通形参签名或建立普通值特化缓存。实际子位置的初始化或错误状态优先于声明布局，递归字段按被访问路径求证，不凭类型无限展开值。

## 原生接口与后端

语言可达原生方法采用单 `NativeCallContext` 参数，读取真实参数、receiver、不可变载荷和数据位置，发布实际返回值与变更效果。注解函数/操作符注入及显式 native func 绑定在发布前检查该签名，失败不插入对应成员或操作符。属性的原生选择要求单上下文；未匹配的引用仍按既有语言表达式属性规则绑定，不能据此声称属性没有注册成员。原生属性调用失败不发布有效结果。原生调用不以宿主对象或包装器后备分派代替普通语言值。Selector、资源工厂、命令格式消费者和属性沿用同一值/位置合同。

26.3 浮点使用数值提供器和 FloatTag；旧目标使用四分量模拟布局。常量与运行时求值遵守各自后端的顺序、精度和异常规则。两种持久化布局不会自动互换。未证明等价的旧浮点算术保留实际库调用。

## 库与验证

当前元数据格式为 MCFL77 v4，增加对象字段合同、字面量类型及显式/隐式工厂标记，并保存声明 AST、固有常量快照、可选性、访问器、子模板身份和声明环境来源；不保存活动 Scope、Place、调用图或特化缓存。函数源码和原生效果声明在导入后用于调用前写检查。v3 及更早的库必须重建；开发期 Kryo 缓存版本为 88，旧缓存也须重建。TypeValue 通过 TypeId 与本地类型描述恢复，不引入运行时反射或全局类型对象注册表。

元数据变更集中升级格式并重建标准库；旧格式和未知格式给出重编译诊断。每个通过验证的完整批次本地提交，不推送。

维护接点与验证入口见 [编译器工程维护指南](../compiler-architecture.md)。
