# 类型系统迁移指南

语言规则以 [规范](./specification.md) 为准；唯一的进度与剩余清单见 [续接记录](./session-continuation-2026-10-04.md)。本次迁移不兼容旧语言写法，也不自动转换已有持久数据。

## 语言写法

`type` 只用于泛型参数。例如 `data Box<T as type>` 合法，普通变量、字段、函数参数或返回值不能存放类型值，嵌套在 any/object 或集合中也不例外。`typealias` 和直接泛型类型表达式保留。

语言不提供 `T!` 后缀。`const` 只限制声明位置再次赋值，允许明确类型的未初始化字段在构造中首次赋值；不要求值编译期已知，也不把可变容器的内容变为不可修改。readonly 泛型实参要求完整、不可变的编译期载荷。

const 的首次赋值必须在所有可达前驱上均未发生。分支或循环中的可能赋值不能被当作未赋值；as 别名保留来源约束，声明别名也不会重置已有值的初始化事实。

dynamic 要求运行时表示，不能将编译器专用载荷强制编码为 NBT。物化保留已经证明的事实，后续运行期操作仍生成真实命令。

`as` 建立同一数据位置上的解释视图。显式数值转换使用 `toInt`、`toFloat`、`toByte`、`toShort`、`toLong`、`toDouble`；编码使用 `toNBT`。能力与精度见 [转换合同](./conversions.md)。

泛型声明支持 `out`、`in`，默认不变；内建 list/dict/map/ImmutableList 的类型参数均保持不变，ImmutableList 的只读接口不引入协变。不提供语言星投影。同一命名空间的 data/object 名字分别唯一，明确对应的伴随对象按声明参数配对。

## 声明、初始化与调用

字段 RHS 的声明类型来自纯绑定与签名查询。绑定不执行用户函数或构造函数，真实初始化按实例执行一次。普通实参的已知值不改变公共参数与返回类型；编译器专用载荷在实际调用中绑定，只有 readonly 泛型实参进入特化键。

纯闭合的普通默认表达式可通过声明绑定保存不可变载荷；依赖 receiver 或普通变量的默认表达式保留词法 AST，不执行初始化探测。缺省实参只在实际省略时求值，并使用声明的词法环境、已绑定 readonly 实参、此前普通实参及实际 receiver。属性 getter/setter 使用真实 owner 和字段位置；表达式属性保留词法 token 间隔，内部访问函数不占用用户可声明的名字。

object 初始化采用规范声明身份，并按依赖执行一次。库恢复重建声明环境与实例访问作用域，不保存源项目的调用图、活跃位置或特化缓存。嵌套在容器实参中的声明身份同样解析到真实声明；访问与独立复制/返回从同一 `readAccess` 和当前 StoredData 的类型描述读取布局，不使用公开无字段占位。访问局部的布局证据只能向独立目标传递，不给源字典键发布 INITIALIZED、常量或长度事实，不改变普通形参签名或建立普通值特化缓存。实际子位置的初始化或错误状态优先于声明布局，递归字段按被访问路径求证，不凭类型无限展开值。

## 原生接口与后端

语言可达原生方法采用单 `NativeCallContext` 参数，读取真实参数、receiver、不可变载荷和数据位置，发布实际返回值与变更效果。注解函数/操作符注入及显式 native func 绑定在发布前检查该签名，失败不插入对应成员或操作符。属性的原生选择要求单上下文；未匹配的引用仍按既有语言表达式属性规则绑定，不能据此声称属性没有注册成员。原生属性调用失败不发布有效结果。原生调用不以宿主对象或包装器后备分派代替普通语言值。Selector、资源工厂、命令格式消费者和属性沿用同一值/位置合同。

26.3 浮点使用数值提供器和 FloatTag；旧目标使用四分量模拟布局。常量与运行时求值遵守各自后端的顺序、精度和异常规则。两种持久化布局不会自动互换。未证明等价的旧浮点算术保留实际库调用。

## 库与验证

当前元数据格式为 MCFL77，保存声明 AST、有限类型描述、闭合默认载荷和声明环境来源；不保存活动 Scope、Place、调用图或特化缓存。TypeValue 通过 TypeId 与本地类型描述恢复，不引入运行时反射或全局类型对象注册表。

元数据变更集中升级格式并重建标准库；旧格式和未知格式给出重编译诊断。每个通过验证的完整批次本地提交，不推送。

验证程序和覆盖重点见 [验证方法](./verification.md)。独立命令执行器验证导出结果及真实旧浮点库调用；当前未配置 Minecraft 服务端。
