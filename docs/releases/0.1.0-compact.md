# MCFPP 0.1.0 体积优化

`./gradlew release` 优先缩小产物，输出到 `build/releases/0.1.0`。快速打包继续使用 `shadowJar`、`shadowDistZip`、`shadowDistTar`、`installShadowDist`；`verifyDistribution` 和快速源码 ZIP `releaseSources` 保留。安装步骤见 [INSTALL.md](../../INSTALL.md)。

发行运行时以生产代码和明确的反射入口作为依赖保留根，继续裁剪这些入口的子依赖。使用 JDK 的 `JarFile.versionedStream()` 按版本 25 合并多版本条目，仅保留实际会加载的类和资源。标准库的 17,001 个文件、139,216,326 字节，通过内容分块合并为 482 个唯一块、5,695,427 字节；全部文件路径和 Minecraft 目标版本保留。没有 ICU 类时清除其遗留资源。选中的类字节、Kotlin 元数据和许可证保持原样，服务清单只保留存在的 provider。

ZIP/JAR 使用标准 DEFLATE，比较 JDK 压缩级别和策略以及 Zopfli 的结果。Unix 发行包及完整源码快照使用 TAR.XZ；API 源码 JAR 单独提供，运行包只含运行所需文件。实现和构建依赖说明见 [build-support](../../build-support/README.md)。

打包器在替换输出前验证全部压缩流、全部 ZIP 条目、全部标准库文件的逐字节还原，以及 XZ 解压后的 SHA-256。压缩缓存仅复用经核对的数据。最终运行时、发行包和源码快照的对应关系以 `release-manifest.json` 和 `SHA256SUMS` 为准。

## 产物体积

Windows、JDK 25.0.4、Gradle 9.2.1、Kotlin 2.4.10，2026-11-04 实际构建：

| 制品 | 字节数 | 对比依据 |
| --- | ---: | --- |
| `MCFPP-0.1.0.jar` | 31,991,651 | 本次快速 `shadowJar` 为 67,835,097，减少约 53% |
| `mcfpp-0.1.0.zip` | 29,204,162 | 优化前发行 ZIP 为 57,111,570，减少约 49% |
| `mcfpp-0.1.0.tar.xz` | 28,918,500 | CLI 与 Unix 启动脚本 |
| `MCFPP-0.1.0-sources.jar` | 1,277,232 | 单独提供的 API 源码 |
| `mcfpp-0.1.0-source.tar.xz` | 约 2.05 MB | 完整源码快照；精确大小和哈希以最终文件及清单为准 |

`lib` 中只有一个运行时 JAR，构建压缩工具没有进入运行时。Unix 启动脚本权限已核对为 `rwxr-xr-x`。完整源码包含构建辅助工具、Gradle wrapper、新增 Kotlin 注解、provider 和调试器源码。
