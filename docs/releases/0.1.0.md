# MCFPP 0.1.0 发行验收

日期：2026-11-04。Windows、JDK 25.0.4、Gradle 9.2.1、Kotlin 2.4.10。

本文保留体积优化之前的发行验收证据，所列哈希对应旧制品。当前 `release` 构建和压缩包的验收见 [体积优化记录](0.1.0-compact.md)。

## 交付结果

`./gradlew release` 将完整发行物放入 `build/releases/0.1.0`。对外使用 `mcfpp-0.1.0.zip` 或 `mcfpp-0.1.0.tar`；解压后将 `bin` 加入 PATH，设置 `JAVA_HOME` 为 JDK 25，即可直接运行 `mcfpp`。操作步骤见 [安装说明](../../INSTALL.md)，版本范围见 [发行说明](../../RELEASE-NOTES.md)。

发行目录包含启动脚本、完整运行时、JVM API 源码 JAR、安装说明和许可证。独立 JAR、完整项目源码快照、`SHA256SUMS` 和 `release-manifest.json` 一同生成；源码快照包含当前工作区的新源码。普通 JAR 使用 `plain` classifier，避免覆盖完整运行时。

本次还将旧 `NBTTest.kts` 的过期 `net.querz` 导入改为现用 `Tag.toNBT`，修复了打包依赖的测试源码编译失败。

## 实际验证

将最终 ZIP 解压后，把安装目录改名为含空格的目录，临时加入 PATH；从另一个工程目录直接调用命令，全部使用后台进程。

| 用户行为 | 实际结果 |
| --- | --- |
| `mcfpp --version` / `mcfpp --help` | 正常，版本为 `MCFPP 0.1.0 (toolchain java25-v1)` |
| `mcfpp init hello`，在工程目录运行 `mcfpp build --offline` | 成功，生成 `pack.mcmeta` 和包含 Hello 输出的入口函数 |
| `mcfpp build --offline --locked` | 成功 |
| MCFPP `@Test` 中对运行期整数运算进行断言，经 DSB 执行 | 1 项通过，无跳过 |
| 错误源码执行 `mcfpp build` | 返回退出码 1，启动脚本保留失败状态 |
| `mcfpp init hello-mni --mni`、`mcfpp build --offline`、`mcfpp test --offline` | 全部成功，生成的 Kotlin/JUnit 测试 1 项通过 |
| `java -jar lib/MCFPP-0.1.0.jar --version` | 成功，版本同为 0.1.0 |
| ZIP 文件布局、源码快照中的新增 Kotlin 注解/provider/调试器源码、SHA-256 清单 | 已核对 |
