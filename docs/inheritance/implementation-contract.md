# data 继承与工厂合同

本文采用[类型组合与工厂计划](../type-system/type-composition-and-factory-plan.md)及已确认的设计决定。源码迁移见[类型系统迁移指南](../type-system/migration.md)，当前验证状态见[实施记录](../type-system/composition-implementation.md)。本合同针对普通 `data`；`object data`、实体模板与类型包装保留各自的内部初始化入口。

## 字段合同与组合

```mcfpp
data Position { var x: int; var y: int }
data Named { var name: string }
data Marker: Position, Named { var active: bool }
```

`Marker` 的数据合同为 `Position & Named & { active: bool }`。父字段与本地字段形成一个扁平布局；相同字段名对应一个逻辑存储槽。声明来源与名义祖先信息保留，用于访问检查、诊断与名义关系查询。结构兼容本身不授予父声明的受保护或私有访问权限。

- 交叉按字段名合并约束，同名字段的类型取交叉；任一来源要求存在，该字段就必须存在。
- 必需字段的类型交叉为 `never` 时，整体合同不可满足。可选字段的交叉为 `never` 时，该字段只能缺失。
- 同一来源经菱形路径出现时去重。父列表顺序不选择获胜字段，也不消解类型冲突。
- 继承声明额外检查成员种类：同名普通 `var` 与 `const` 来源冲突必须报错。普通交叉类型仍按字段类型计算约束。
- 循环父图在声明完成时拒绝；普通声明、泛型特化和库恢复遵守相同规则。

`var label: string?` 表示字段可以缺失；存在时必须为字符串。对象字面量可以带有目标合同以外的字段，赋值、参数、返回与泛型约束使用同一结构子类型关系。字段初值与函数体不参与对象类型身份。

`const` 在声明时固定为完整编译期值，其合同使用对应的字面量类型。显式对象字面量和显式工厂返回值都须提供必需常量字段及匹配的值。

## 接收者函数

模板内的 `func` 使用该模板类型的接收者；成员调用负责绑定接收者。子类型值可以满足接收者合同，函数可见性、重载与实参兼容性交给普通函数系统处理。

函数保留原声明所有者，不复制到子模板的本地函数表。继承声明不建立方法覆盖链、父列表分派顺序或 `super` 分派。依赖旧覆盖或父构造阶段的代码须按迁移指南改写。

## 返回完整值的工厂

```mcfpp
data Point {
    var x: int
    var y: int
    new(x: int, y: int) { return { x, y } }
}
data NamedPoint: Point {
    var name: string
    new(x: int, y: int, name: string) { return { x, y, name } }
}
```

`new` 是类型命名空间中的普通工厂，返回完整的 `Self`；工厂没有接收者，工厂体中没有 `this`。所有参数与实参都显式给出，编译器不添加隐藏首参数。`Point(2, 3)` 与 `Point.new(2, 3)` 使用普通函数重载选择；每条可达成功路径都须显式 `return`，返回值须满足完整字段合同。普通实例方法与扩展函数仍保留接收者和 `this`。

字段初值足以形成完整值时生成零参数工厂；空模板的默认工厂返回 `{}`。显式零参数工厂替代该隐式版本，其他显式重载与有效的隐式工厂共存。

父初值与父工厂不自动运行。子工厂自己提供完整的父字段，需要父工厂结果时显式调用，并逐字段组合返回值。例如：

```mcfpp
data ExplicitNamedPoint: Point {
    var name: string
    new(x: int, y: int, name: string) {
        var point = Point.new(x, y)
        return { x: point.x, y: point.y, name }
    }
}
```

`Point.new(x, y)` 返回独立且完整的 `Point` 值；子工厂逐字段组合该值与自己的字段，形成完整的子类型返回值。工厂调用只使用普通可见性、参数兼容性和重载规则，不检查调用者与目标类型之间是否存在名义祖先关系，也不绑定实例接收者。

## 视图、存储与库

`as` 是显式解释视图，结构不兼容本身不阻止创建视图。共享位置的写入同时遵守视图合同、真实存储合同和常量保护；联合字段写入必须满足所有分支的约束。将值赋给独立变量时仍遵守普通复制语义。

库保存字段合同、可选性、常量字面量、声明来源、名义父关系和工厂标记，恢复后重新建立相同的组合与调用规则。升级元数据格式后重新生成标准库和用户库。
